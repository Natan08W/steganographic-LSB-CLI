This is a simple "Lowest Significant Bit (LSB) Steganographic Encryptor" that uses an XOR mask to encode and decode texts to and from the lowest significant bits of an image. 

bit_ops.py stores most of the bitwise operations, excluding the XOR mask itself.
crypto.py stores the encryption procedure using a hashed keystream that is generated by the provided key and applying that stream to an XOR mask against the lowest significant bits of a channel in a pixel.
engine.py stores the majority of the operations aswell as using operations from the other two files to complete the actual data handling structure.
main.py handles the user CLI aswell as returning inputs and outputs.

The CLI follows standard formatting where -i is input, -o is output, -k is key, -f is file and -m is message.

Some examples commands that you can use:
- python3 main.py encode -i start.png -o output.png -m "This is a message" -k "KEY"
- python3 main.py decode -i output.png -o output_msg.md -k "KEY"

If you wish to decode the files already provided, you can use the decode instruction where k = the file name.
